# Your travel log lives here

This directory holds your real dataset — the app uses it automatically whenever
`data/trips.js` exists (run with `DEMO=1` to see the synthetic demo instead):

```
data/
  trips.js           — trip metadata array + HOME marker (copy demo/trips.js
                       as a starting point and replace its entries)
  routes/*.geojson   — one route file per trip, generated by `npm run route`
                       (from a stops list) or `npm run import` (from the
                       travel-planner app)
```

See the "Adding trips" section of the project README for the full workflow.

If you deploy from a git-connected host (e.g. Cloudflare Pages), commit this
directory — the build needs it. Keep the repository private if your travel
history shouldn't be public.
